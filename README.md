# DermaScan AI

## About

DermaScan AI is a project I'm working on to use machine learning for skin image classification.

The main idea is to train a model that can look at a skin image and predict which skin condition it may belong to.

I started by preparing the dataset and training the model. Now I'm working on improving it and building a simple website where users can upload an image and get a prediction.

## Tools I Used

- Python
- TensorFlow & Keras
- Machine Learning
- CNN (Convolutional Neural Network)
- Streamlit (for the website)

## Project Files

- `dermascan_finetuned.keras`: The trained model.
- `github_projects_csv.ipynb`: A notebook from my previous GitHub data analysis work.

## Current Progress

- Prepared the dataset.
- Trained and fine-tuned the model.
- Saved the trained model.
- Working on the website and connecting it to the model.

## What's Next?

I want to improve the model's performance, build the website, and make the whole project easier to use.

## Note

This project is for learning and educational purposes. Its predictions are not medical diagnoses and should not be used instead of advice from a healthcare professional.
